# web/ — static site for Vercel

`web/public/` is generated by `python3 scripts/build_site.py` (catalog browser + operator console + docs) and committed, so Vercel serves it without a build step (`vercel.json` at repo root).

- `index.html` — searchable/filterable browser for the 1000-scenario catalog
- `console.html` — the operator console; point it at a running stack with `?api=http://<host>:5000`
- `docs/` — README, strategy, known issues, catalog table

Deploy: `vercel --prod` from the repo root. Rebuild after regenerating the catalog.
